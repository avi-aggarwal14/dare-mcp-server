# dare-mcp

A short alias for **[`dare-mcp-server`](https://www.npmjs.com/package/dare-mcp-server)** —
an MCP server that lets Claude generate video and images through your own
[Dare](https://trydare.com) credits.

This package contains no logic. It depends on `dare-mcp-server` at an exact matching version
and forwards straight to it, so both names always behave identically.

```bash
npx dare-mcp setup          # same as: npx dare-mcp-server setup
```

**Documentation, issues and source: <https://github.com/avi-aggarwal14/dare-mcp-server>**

Not affiliated with, endorsed by, or supported by Dare.
